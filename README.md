# 薄肌计划

一款装在 iPhone 上的个人减脂 / 薄肌 App（PWA）。内容按你的情况定制：

- **173cm / 75kg（150 斤）**，目标体重约 **66kg**，主打「薄肌」——体脂够低 + 线条清晰，不追求大块头。
- 每天在**食堂**吃饭 → 内置食堂红绿灯、打菜口诀、三餐模板。
- 一周四练（胸 / 肩 / 背 / 腿），每天 1–2 小时；白天久坐工位学习。
- 附**皮肤变好 + 脸部轮廓 / 下颌线 + 变帅清单**。

## 怎么用

### 1. 在自己电脑上预览

需要 Node（本机已有）：

```bash
node serve.mjs
```

然后浏览器打开 http://localhost:8080 。手机和电脑连同一 Wi-Fi 时，手机浏览器也能打开 `http://<电脑IP>:8080` 预览。

### 2. 装到 iPhone 上（关键步骤）

PWA 需要 HTTPS 才能安装。选一种方式把它放到网上：

- **免费托管（推荐）**：把整个文件夹上传到 GitHub Pages / Vercel / Netlify，拿到一个 `https://…` 链接。
- 拿到链接后，在 iPhone 的 **Safari** 里打开它 → 点底部「分享」→ **添加到主屏幕** → 完成。
- 之后从主屏点开就是全屏 App，图标是等高线那款；联网加载一次后**离线也能用**。

> 注意：一定要用 Safari（iPhone 自带浏览器）做「添加到主屏幕」，Chrome 不支持。

### 3. 每天用它做什么

- **今日**：看体重/BMI、当天练什么，打勾每日清单（睡眠/防晒/护肤/步数/蛋白），打卡喝水。
- **饮食**：食堂怎么点菜、每餐模板、蛋白质怎么吃到 140g。
- **训练**：胸/肩/背/腿四个动作计划 + 薄肌要点。
- **皮肤**：护肤流程 + 下颌线/脸部轮廓攻略。
- **进度**：每天空腹称重记录，看体重趋势图；每周拍三张照片。

## 数据说明

- 所有记录（体重、打卡、喝水）只存在**你这台设备的浏览器里**（localStorage），不上传任何地方；清除网站数据会清空记录。
- 热量目标 **1900 kcal / 蛋白质 140g** 是按「173cm / 75kg / 一周四练 / 白天久坐、假设年龄 22 岁左右」估算的，体重明显变化后可再微调（改 `js/app.js` 顶部的 `START` / `TARGET`）。

## 文件

```
index.html        页面结构与全部内容
css/style.css     蓝图（blueprint/等高线）设计系统
js/app.js         交互 + 本地存储 + 体重折线图
manifest.json     PWA 配置
sw.js             离线缓存
icons/            图标（scripts/gen-icon.mjs 生成）
serve.mjs         本地预览服务器
```
