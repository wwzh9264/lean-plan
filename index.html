薄肌要点
1

次数 8–15、中等重量，慢下快上（控制离心）

2

渐进超负荷：每周在次数或重量上 + 一点点

3

减脂期别降重量：保住力量 = 保住肌肉

4

复合动作为主，组间休息 60–90 秒

5

想要「薄」的身材：重点不是练小，是体脂够低 + 肌肉线条清晰

有氧与步数
•

训练后 20–30 分钟快走 / 坡度走，心率约 120–140

•

休息日 30–45 分钟低强度有氧

•

日常步数 8000–10000——久坐党减脂的关键增量

护肤流程（男生极简版）
早

温和洁面 → 爽肤水（可选）→ 保湿乳 → 防晒（必涂）

晚

洁面（洗掉防晒和汗）→ 保湿

运动后

及时洗脸 / 洗澡，别让汗和油闷着

长痘

别挤、少糖少奶、勤换枕套、规律作息；反复不好去看皮肤科，别信偏方

脸部轮廓 · 下颌线

按重要性排序。核心公式：低体脂 + 低水肿 + 好体态 + 紧致皮肤。

减脂到 13–15%脸是最后瘦的，全身减脂脸自然收紧——别急，坚持就有效

控盐控钠食堂偏咸，多喝水排钠；睡前别吃太咸，减少晨起水肿脸

睡够别熬夜熬夜 = 水肿 + 皮肤差，下颌线直接模糊

体态挺直颈前倾 / 圆肩会让双下巴明显——每天靠墙站（后脑、肩、臀、脚跟贴墙）、下巴微收

用鼻子呼吸长期口呼吸会让下巴后缩、脸型变差

皮肤紧致防晒 + 保湿 + 吃够蛋白质

皮肤变好的关键

防晒（每天，阴天也涂）抗老、防痘印加深的第一位

睡够 7–8 小时皮肤修复、气色

少糖（奶茶、甜点）糖化让皮肤暗沉、爱长痘

喝水 2–3L保湿、代谢

温和清洁 + 保湿别过度清洁，破坏屏障反而更油更痘
